# PIXONA Improvements - Inspired by Tonfotos

## Overview
This document outlines comprehensive improvements to PIXONA based on Tonfotos features and best practices in photo management applications.

## 🎯 Phase 1: Enhanced Metadata System (Priority: HIGH)

### 1.1 Improved Metadata Structure
Implement a comprehensive metadata tracking system similar to the `.pixona_meta.json` file:

```typescript
interface PhotoMetadata {
  // Core identifiers
  id: string;
  filePath: string;
  fileName: string;
  fileHash: string; // SHA-256 for duplicate detection
  
  // Timestamps
  dateAdded: number;
  dateModified: number;
  dateTaken: number; // from EXIF
  lastScanned: number;
  
  // EXIF data
  exif: {
    camera: string;
    lens: string;
    focalLength: number;
    aperture: string;
    iso: number;
    shutterSpeed: string;
    gpsLatitude?: number;
    gpsLongitude?: number;
    gpsAltitude?: number;
  };
  
  // AI-detected features
  faces: Array<{
    id: string;
    personId?: string; // Link to People database
    boundingBox: { x: number; y: number; width: number; height: number };
    confidence: number;
    embedding: number[]; // Face recognition vector
    ageEstimate?: number;
  }>;
  
  // Organization
  tags: string[];
  albums: string[];
  eventId?: string;
  locationName?: string; // Reverse geocoded location
  
  // Quality metrics
  qualityScore?: number;
  blurScore?: number;
  exposureScore?: number;
  
  // Duplicate detection
  perceptualHash: string; // pHash for near-duplicate detection
  duplicateOf?: string; // Reference to original if duplicate
  similarPhotos?: string[]; // IDs of similar photos
  
  // Processing status
  indexed: boolean;
  facesDetected: boolean;
  thumbnailGenerated: boolean;
  analyzed: boolean;
}
```

- Photo content similarity


### 2.3 Advanced Duplicate Detection
**Multi-Level Approach:**
1. **Exact Duplicates:** File hash (SHA-256)
2. **Near Duplicates:** Perceptual hashing (pHash)
3. **Similar Photos:** Deep learning embeddings

**Features:**
- Detect edited versions of same photo
- Find photos from burst mode
- Compare across different resolutions
- Smart selection of best version

```typescript
interface DuplicateGroup {
  id: string;
  primaryPhotoId: string; // Best quality
  duplicates: Array<{
    photoId: string;
    similarity: number;
    type: 'exact' | 'near' | 'similar';
    qualityScore: number;
  }>;
  spaceWasted: number; // Bytes
  recommendation: 'keep-all' | 'keep-best' | 'manual-review';
}
```
